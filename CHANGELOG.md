# Changelog

## 0.1.1

- The package moves to the `@noburi` scope: install `@noburi/nodemailer`. `@pulsesend/nodemailer` is deprecated. No code change.

## 0.1.0

- First release: Nodemailer transport for the PulseSend API (addresses, html and text, attachments and inline images, custom headers, tags, scheduling, templates, tracking, idempotency key, retries on 429, 5xx and network errors).
